# SuperTux 0.7.0 Nintendo 3DS port

Playable native port using Citro2D/Citro3D and NDSP, with a top gameplay screen
and bottom interface. New 3DS/New 2DS hardware is the main performance target.

- [Build on Windows](BUILDING.md)
- [What to commit to a SuperTux fork](GITHUB.md)
- [Current features and installation](ENGINE-README.md)

Build from the repository root with `python 3ds/build_engine.py --package`.
Keep upstream code/art/audio licenses and credits. The earlier `build.py` and
`source/main.cpp` are historical bring-up code; `build_engine.py` is the game.
